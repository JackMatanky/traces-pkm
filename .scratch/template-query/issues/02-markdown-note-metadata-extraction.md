## Agent Brief

**Category:** enhancement
**Summary:** Layer `Note` records onto the `FileIndex` for markdown files. Parse each `FileKind::Markdown` file using `pulldown-cmark` into a `Note` struct storing YAML frontmatter, `List`/`ListItem` structure (with task completion state), outlinks (markdown links and wikilinks), and parser state for code-region byte ranges (to exclude them in #03). Persist to a `notes` redb table keyed by path. `tasks()` is a method on `Note` that derives task list items.

**Blocked by:** #01 (unmerged in `.worktrees/fileindex-baseline`): needs `FileIndex`, `FileRecord`/`FileKind::Markdown`, `IndexStore`. Do not start until #01 merges.

**Key interfaces:**
- `index/markdown.rs`: pure function `&str -> Note` over `Parser::new_ext(src, opts).into_offset_iter()`. Opts: `ENABLE_TASKLISTS | ENABLE_YAML_STYLE_METADATA_BLOCKS | ENABLE_WIKILINKS`.
- `Note { frontmatter, lists, outlinks }` (plus internal code-region byte ranges for #03).
- `Note::tasks()` method filtering list items that carry task completion state.
- Extend `IndexStore` with the `notes` table; `FileIndex::build` parses markdown files and `persist`/`load` round-trip both `file_records` and `notes` tables.

**Acceptance criteria:**
- [ ] Markdown Notes store a `Note` record in the `notes` table in addition to their `FileRecord`.
