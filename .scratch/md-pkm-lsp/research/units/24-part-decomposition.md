# Ticket 24 part decomposition — completion architecture research units

Splits [24-completion-architecture](../../issues/24-completion-architecture.md) into bounded research units, one per downstream research subagent. Ticket 24 decides the *unifying* completion architecture (context detection/dispatch, trigger set incl. rumdl collisions, `completionItem/resolve` lazy detail, snippets) once the per-feature completion decisions are settled.

## Constraints supplied by resolved tickets (read these Answers first)

- **09 / 12** (framework & concurrency): `tower-lsp-server` with `concurrency_level(1)` — handlers run **sequentially on one dispatch slot**; `$/cancelRequest` = stale-result discard only (no cooperative interruption). A slow completion handler head-of-line-blocks everything.
- **11 / 39** (spans): span-aware AST (links/tags/headings/inline fields carry `Range<BytePos>`, `LineIndex` for UTF-16 mapping), **full re-parse per edit**, no incremental re-parse; frontmatter spans via `noyalib` `Spanned` (19).
- **13 / 14** (buffer & cache): editor buffer authoritative while open; `ContentResolver` for text access; LRU AST cache tier; debounces provisional (25 owns final tiers).
- **15** (links): wikilink completion via `fuzzy-matcher` scoring, heading completion via GitHub-slug matching; Traces owns wikilinks, rumdl owns standard links; "create note" affordance for unresolved targets.
- **16** (tags): `#` trigger + five syntax guards (code blocks/spans, URLs/autolinks, word-internal, `[[#heading]]`/`[link](#anchor)` reserved for heading completion, `# ` ATX heading); compound `filter_text`; `KEYWORD` kind; `label_details.detail` usage stats.
- **17** (footnotes/callouts): `[^` footnote-label completion; `>` callout-type completion (13 canonical + aliases + config).
- **18** (daily notes): hybrid ±7-day date completion; **completion dispatch explicitly deferred to 24**.
- **19** (frontmatter/inline fields): three-layer completion (schema > global > inferred) with `sortText` layer prefixes and badges; triggers `[` and `:` with `CodeRegion` exclusion running **first**, exact regex validation for `:`; spanning `textEdit` via `byte_to_utf16_cu`.
- **20** (schema): file-field value completion, cap 100, `is_incomplete: true`, relevance sort (recent → same folder → alphabetical), overlay-merged.
- **21** (query): cursor-in-query = O(N) depth counter over `{{`/`}}`; completion contexts after `#`, `@`, filter LHS, operator/RHS; `textEdit` with explicit range for **all** completions; triggers `#`/`@` filed for 24; Phase 2 deferred `(`/`"` triggers and `completionItem/resolve`; **24 owns the shared completion-generation function + trigger reconciliation**.
- **22** (template): helper-namespace member completion (`ui.`/`file.`/`date.`/`query.`/`tasks.`/`schema.`) **files a `.` trigger request that collides with rumdl's `(`,`#`,`/`,`.`,`-`** (research/22:175-177); owed inputs to 24 = data source, staging proposal, trigger `.` request, local-before-global ordering, Q15(c) degrade hand-off line **incl. the construction-failure "intelligence-disabled" third state** (research/22:350); filter/test/namespace completion applies only outside query-string contexts.
- **23** (tasks): `- [` checkbox completion gated on `scan_marker_prefix` state (`Incomplete` offers; `Rejected` **falls through to 19's contexts**; `Complete` → field/value layer); `📅 ` emoji token + stage-2 date values; `[due:: ` date values; seam **19 = position predicate, 23 = candidates/content, 24 = dispatch**; `sort_text` = config insertion order, `preselect` top, no space trigger, `Invoked` fallback + `TriggerForIncompleteCompletions` re-requests; **`[`-context ambiguity at `- [t` owed to 24**.
- **33** (perf): **completion < 20ms** p-target; inverted index built now; gopls's budget-reduction pattern as prior art.
- **03 / 32** (rumdl): three-setting coexistence contract; `enableLinkCompletions=false` makes rumdl stop invoking its link completion **and not register its link-target trigger characters `(`, `#`, `/`, `.`, `-`** — fenced-code completion still runs (docs digest:1985-1991); 32 owns the documented boundary.
